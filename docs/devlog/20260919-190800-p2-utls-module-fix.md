- github.com/refraction-networking/utls v1.6.5
- golang.org/x/crypto v0.38.0

其余已声明版本满足当前最高约束：x/net v0.23.0、x/sys v0.33.0。

## 修复

仅修改module metadata：
- go.mod：golang.org/x/text v0.14.0 -> v0.25.0 // indirect。
- go.sum：替换为v0.25.0 module/content checksum。
- realityfront、faketcp、tlsrecord产品代码不变。
