Lane owner 固定一个 incarnation 的：
- role（client/server）；
- incarnation nonce / TunnelID；
- client/server direction record limits；
- exporter-derived C2S/S2C keys；
- FEC path-level profile：off 或 20:4/8/10/12/16/20；
- TX/RX 独立 unified pathmtu Budget；
- TX/RX 独立 LINK/FEC path；
- TX record Sealer / RX record Decoder；
- owner timer expiry 与统计。

方向映射固定：
- client TX -> ServerLimit + C2S；client RX -> ClientLimit + S2C；
- server TX -> ClientLimit + S2C；server RX -> ServerLimit + C2S。

`ServerLaneConfigFromAdmission` 只读取 P2 已有 `ServerAdmissionSession.Negotiated` 和 `ServerAssociation.PeerTCPProfile`。server TX 预算受普通 peer SYN 实际 MSS/缺省536约束；server RX mirror 使用服务端 SYN-ACK 已发布的 DefaultMSS。没有修改 P2 接口。

FEC profile 是 incarnation immutable：LaneConfig、TX/RX pathmtu config、两个 FECPath 必须一致，record direction limit 也必须与 role 对应；不一致在 NewLane 前/构造时明确失败。没有热切换 block、动态选档或第二套 FEC 实现。

`ParityShards=0` 在 datapath/pathmtu 只表示 FEC off；WIRE_SPEC 已补充说明，不把归档 header parser 的历史 parity=0 -> 20:20 兼容解释误用为 path-level off。

## 所有权与 no-HOL

Outbound：
`application datagram -> LINK fragment -> optional FEC -> tlsrecord seal -> owned immutable WireRecord`。

WireRecord 在返回前拥有独立字节；后续 LINK/FEC encoder 或 record seal 不会修改旧 wire。FakeTCP steady-state repair 后续只需缓存并重发该最终 wire，不应再次 seal。

Inbound：
`FakeTCP payload -> tlsrecord Decoder -> FEC/LINK -> application datagram`。

record authentication/structure错误和单个 FEC/LINK错误分别计数，并继续处理本 payload 中后续独立 record，不建立 expected PN。DetachTransition 返回的 copied early record payload 可由 `InboundTransition` 直接交 owner；TCP Seq 不转成 record 顺序。

`Expire(now)` 是显式 owner timer hook，不产生网络流量，不等待新包；停流后仍驱动 FEC 3秒绝对 retirement 与 LINK expiry。

`Close` 只释放当前 lane 的 crypto/FEC/reassembly 状态，不影响 sibling lane。
