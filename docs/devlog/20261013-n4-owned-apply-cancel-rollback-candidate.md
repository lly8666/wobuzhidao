## The new atomic Go-only change
Official Windows runWindows uses applyOwnedNetwork(ctx) instead of an uninterruptible exec.Command PowerShell Apply. The Apply child's process is now controlled by exec.CommandContext; GUI Stop/owner EOF cancels it.
